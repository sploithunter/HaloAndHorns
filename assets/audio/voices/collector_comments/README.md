# Coin Pup comments

Six ElevenLabs recordings using the user-approved angel/demon voices and multilingual pilot settings.
Canonical script: `configs/voice_comments/collector.json`. Runtime IDs and timing:
`configs/collector_voice.lua`. No API keys are stored here.

`manifest.json` records generation inputs, hashes, durations, costs and request IDs;
`validation.json` records decode, timing, clipping and source checks. Alignment sidecars are
provider timing, not an independent transcription. `roblox_ids.json` records completed uploads;
upload completion is distinct from moderation/delivery. English is the per-line fallback.

Playback is ownership-gated; see `docs/wiki/TUTORIAL_VOICE.md` for the trigger contract.
