# Merge tutorial — Heaven and Hell recording scripts

2026-09-08 · English · 40 paired cues / 80 recordings

Heaven uses the approved angel voice: encouraging and patient. Hell uses the approved demon voice: amused, lightly mocking, and accurate. Both follow the player’s assigned bay side, including powers and workshop menus. Spoken guidance supplements existing localized and device-specific text.

The current route is setup → Wave 2 bulwark → Wave 4 cannon → Wave 6 power → optional Wave 8 egg improvement → Wave 10 slots → Wave 12 enhancement → Wave 14 optional Quartermaster introduction. Existing progress and skipped lessons remain authoritative. No visit or purchase is required at the Quartermaster.

World faces use the shared camera-periphery presentation; portraits appear only over menus. Required hands-on steps receive an idle reminder after 45 seconds, then every 60 idle seconds. Menus and combat pause reminders; progress resets them. Completed/reborn players receive no tutorial nudges. Help clips wait for a stable menu phase and are skipped if it changes.
