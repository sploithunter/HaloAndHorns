# Heaven / Hell flora, fauna, altars — quote pack

Sheets live in `docs/art/quote_refs/`. Every image is a **local HaloAndHorns file**
(`assets/concepts/layer_3_review/` or `assets/exports/props/meshy_mission_decor/`).

style bar. Heaven One / Two and Hell One / Two use the same language with
narrower palettes (cloud/pearl, crystal/cherry, ash/bone, rot/sulfur).
